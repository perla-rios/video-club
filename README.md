# Video Club

## Descripción del proyecto

Video Club es un proyecto académico de Ingeniería de Software cuyo objetivo es desarrollar un sistema sencillo para registrar y consultar información de películas.

El sistema permitirá registrar películas, mostrar una lista de películas, buscar títulos y consultar información básica como el género y el año de estreno.

El proyecto se desarrollará de manera gradual, aplicando herramientas de control de versiones y buenas prácticas de desarrollo de software.

## Comenzando

Estas instrucciones describen los requisitos y los pasos necesarios para preparar el entorno de trabajo del proyecto.

### Requisitos previos

Para trabajar en el proyecto se necesitará:

* Una computadora con Windows.
* Git para el control de versiones.
* Un editor de código.
* Un lenguaje de programación que se definirá durante el desarrollo.

### Instalación

1. Descargar o clonar el repositorio del proyecto.
2. Abrir la carpeta del proyecto en el editor de código.
3. Preparar el entorno de desarrollo cuando se implemente la aplicación.

### Ejecución

Las instrucciones para ejecutar el sistema se agregarán cuando se desarrolle la aplicación.

## Pruebas

Se realizarán pruebas para comprobar que las funciones del sistema trabajen correctamente.

### Pruebas funcionales

Se verificará que el sistema permita:

* Registrar una película.
* Mostrar las películas registradas.
* Buscar una película por su título.
* Consultar el género y el año de estreno de una película.

### Pruebas de estilo

Se procurará mantener el código organizado, legible y fácil de modificar.
